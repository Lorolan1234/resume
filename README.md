# Сайт-визитка Родиона Аветисова

Статический сайт в формате переписки в Telegram. Ничего не грузит со сторонних серверов: шрифты (Onest, Golos Text, IBM Plex Mono) и библиотека анимации Motion лежат в `assets/`, поэтому сайт одинаково работает из России и из-за рубежа.

## Файлы

- `index.html` — весь сайт
- `photo.jpg` — фото для шапки и профиля
- `wallpaper.svg` — узор фона, как в Telegram
- `Avetisov.R.pdf` — резюме для скачивания
- `assets/fonts/` — шрифты, `assets/motion.js` — анимации

## Публикация на GitHub Pages

1. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
2. Для своего домена: добавить файл `CNAME` с именем домена, а у регистратора прописать A-записи на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
3. Включить «Enforce HTTPS», когда GitHub выпустит сертификат.

## Перенос на другой хостинг

Скопировать содержимое папки целиком в корень сайта. Сборка не нужна.
